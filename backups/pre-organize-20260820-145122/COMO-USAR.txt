COMO APLICAR — FIX GIFs (sem botão de baixar)
============================================

Problema: GIFs apareciam como arquivo pra baixar no WhatsApp Web.
Causa: envio por URL remota ou GIF cru (sem converter pra MP4).

Solução neste reactions.js:
- Baixa o media como Buffer
- Converte GIF/WebP → MP4 (ffmpeg, H.264, max 480px, 8s)
- Envia SÓ buffer com video + gifPlayback: true
- NUNCA envia { url } (isso gerava o botão de download)

APLICAR (escolha 1):
---------------------
# Na pasta do bot (onde está src/plugins):
mkdir -p src/utils
cp /caminho/para/reactions.js  src/utils/reactions.js

# Ou extraia o zip inteiro por cima do bot:
# unzip -o nyx-gif-reactions-fix.zip

OBRIGATÓRIO depois de copiar:
-----------------------------
1. Confirme que o arquivo existe:
   ls -la src/utils/reactions.js
   # deve ter "toMp4" e "gifPlayback" dentro:
   grep -c toMp4 src/utils/reactions.js

2. Confirme ffmpeg no servidor:
   which ffmpeg
   # se não tiver: sudo apt install ffmpeg   (ou pacman -S ffmpeg)

3. REINICIE o bot por completo (pm2 restart / systemctl / matar e subir de novo)
   Só recarregar plugin às vezes NÃO pega o utils novo.

4. Teste:
   .beijo @alguem
   .abraco @alguem

No log do bot você deve ver algo como:
  [reactions] baixou 1234567 bytes | gif=true ...
  [reactions] convertido 1234567 → mp4 234567 bytes

Se aparecer "ffmpeg falhou", instale/corrija o ffmpeg e reinicie de novo.
